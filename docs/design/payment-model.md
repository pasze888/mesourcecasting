# 付费模型与行为语义

> 本文讲行为与策略。配置键名与默认值见 [README.zh-CN.md](../../README.zh-CN.md#配置)，
> 实现机制（Mixin 接管点、时序）见 [mixin-interception.md](mixin-interception.md)，
> 超越维度那一路的具体接法见 [beyond-dimensions.md](beyond-dimensions.md)。

## 魔源来源

施法花费先从**存储网络里的魔源**扣，扣不掉的余额才落到玩家自身魔力。两条来源通道按装了哪些
模组启用，**至少装一条**：

| 来源 | 什么情况下算可用 | 前置 |
|---|---|---|
| ME 网络 | 装了 AE2 与 Ars Énergistique，背包里有一台已绑定接入点的 AE2 无线终端，且绑定的接入点仍是有效网格节点 | Ars Énergistique 提供 ME 魔源键 `arseng:source` |
| 超越维度的维度网络 | 装了 Beyond Dimensions，玩家属于某个维度网络，且该网络被设为主网络 | 只认主网络 |

两路都可用时，按配置 `sources.me_first` 的顺序依次抽取：默认先花 ME 网络的魔源，不够才动
维度网络；把该项关掉则反之。两路的可用量是**各自独立**试算后相加的，「两路加起来够付」即通过判定。

## 两种付费策略

配置项 `payment.network_pays_full_cost` 决定网络与玩家魔力的分工：

- `true`（默认）：网络优先付**整笔**花费——来源链里的魔源够用时，施法完全不消耗玩家自身魔力
- `false`：网络只补**缺口**——玩家魔力先照常扣，只有玩家付不起的部分才由网络承担；
  玩家魔力够付整笔时网络一点不动

两种设置下，「来源链与玩家魔力加起来仍不足 → 不施法」这条都成立。

## 优先级

`来源链的魔源 → 玩家自身魔力`，网络优先。默认配置（付整笔）下，只要来源链里有足够魔源，
玩家魔力一点不掉；切到「只补缺口」后，玩家魔力会先照常消耗，网络只兜住玩家付不起的部分。

来源链内部两路的先后由 `sources.me_first` 决定，见上文。

## 取用范围

- **ME 网络**：绑定**一次即可**——不做接入点距离校验，只要终端绑定过的接入点方块仍是有效网格
  节点就可用。（这是刻意的设计选择，而非沿用 AE2 原版无线终端的距离限制。）
- **维度网络**：只认玩家的**主网络**，与超越维度自身界面和快捷键的语义一致——玩家用它的
  「主网络切换器」就能决定花哪个网络的魔源，不必逐个去猜。玩家不属于任何网络、或没设主网络时，
  这一路不参与。

## 失败时的表现

**失败提示只有 Ars Nouveau 原版那一条**：最终判定为 false 时由 `SpellResolver.enoughMana`
（弓与弩走 `SpellCrossbow`）发 `ars_nouveau.spell.no_mana`——金色聊天栏一行 + 魔力 HUD 红条闪
35 tick。本模组不发任何消息：「网络解析不出来」「网络里没有魔源」「来源链凑不够」都只是
「这次没有网络可用」，玩家看到的与原版完全一致，因此也无从由提示区分是哪一种。

以默认配置（网络付整笔）为例：

- 玩家魔力够整笔 → 原版判定直接通过，网络不参与，玩家魔力照常扣
- 玩家魔力不够、来源链够付整笔 → 判定通过，扣费时网络全额支付，玩家魔力一点不掉
- 玩家魔力与来源链加起来仍不够整笔 → 判定不通过，法术不放，原版报「魔力不足。」
- **默认配置下网络必须一次付清整笔**：只付得出一部分同样是判定不通过、法术不放，网络一滴
  都不会被抽走；把 `network_pays_full_cost` 关掉后网络只需补上玩家的缺口，而玩家魔力会被扣空
- 极端情况：预检通过后、扣费前来源被并发抽走 → 网络实付不足，玩家按自己现有魔力付
  （宁可少付也不透支），法术已经结算放出。成因见
  [mixin-interception.md](mixin-interception.md#与-ars-nouveau-原生时序的关系)；
  两路来源指向同一个池时它更容易发生，见下节

## 两路来源指向同一个池时

超越维度的 AE 存储元件是**读写直连**：插进 ME 驱动器后，ME 网络里的 `arseng:source` 就是
该维度网络里的魔源，从 ME 侧抽走会真实减少维度网络。这时两路来源指向同一个池：

- **扣费不重复抽**——链上按顺序取，每取一次都从 `remaining` 里扣掉，前一路真抽走的量后一路拿不到
- **判定会重复计数**——判定只做模拟、不改变网络，两路各自模拟的是同一个池，可用量会虚高

由此多出一个边界：当维度网络实际不够、玩家魔力又不足以补齐差额时，「网络够不够」的预检
可能因为虚高的和而通过，扣费时网络只能付出它真实拥有的那部分，余额由玩家魔力补，玩家魔力
不够就只付了这些——法术已经结算放出。

这是已知且刻意保留的行为：

- 两路**真独立**时（ME 里放的是 Ars Énergistique 的魔源元件、维度网络没有插磁盘）它给出完全
  正确的结果，而这种情形与重叠无法区分——AE2 没有公开 API 能枚举「某个存储元件绑定的是哪个
  维度网络」
- 改成保守判定（两路取大而非求和）会在两路独立时低估，把「明明够」变成「提示魔力不足、
  不施法」，对玩家更糟

顺带一提：`sources.me_first = false` 时先走维度网络直连，抽同样的魔源不消耗 ME 网络能量；
但它同样消除不了判定虚高，只是换了抽取通道。

## 只装了一条通道时

没装的那条通道整条跳过；装了却解析不出可用来源（没有已绑定的终端、没有主维度网络）的同样跳过。
两者都只是「少一路来源」，本模组不为之提示。

| 装了什么 | 可用来源 | 说明 |
|---|---|---|
| AE2 + Ars Énergistique | 只有 ME 网络 | `sources.me_first` 无效果 |
| 超越维度 | 只有维度网络 | `sources.me_first` 无效果 |
| 两者都装 | 两条 | 按 `sources.me_first` 的顺序取用 |
| 两者都没装 | 无 | 本模组静默放行，完全等同原版 Ars Nouveau |

最后一行是刻意的：「一条通道都没装」是玩家的安装选择，不是配置错误。判定失败一律由原版报
「魔力不足。」，本模组在任何组合下都不发自己的消息。
